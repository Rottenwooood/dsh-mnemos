   发布前建议至少跑 10-20 题蒸馏模式小样本，确认真实模型产出质量。
2. 升级路径：schema user_version=1，迁移靠 ALTER 补列；从旧版本升级到
   新版本的完整路径（数据不丢）只在开发库上走过，缺正式的升级测试。
3. 长期稳定性/压力：无并发写入测试、无大数据量（几千条记忆）索引/搜索
   性能基准、无长时间运行（内存泄漏、WAL 膨胀、git 仓库膨胀）观测。
4. 多环境矩阵：只在当前 web profile 验证过；无 LLM 的 profile（headless）、
   不同 DSH 版本、Windows/macOS 未测。
5. npm 发布动作本身未执行：`npm publish --dry-run` 已过，但真实发布
